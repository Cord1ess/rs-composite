04New findings

A1 The preloaded textures download twice medium Â· measured

Measured against the production server: lights, land and borders each produce two requests â€” the main thread's <link preload> fetches them in full, then the worker's own fetch misses the document-scoped preload cache and re-requests. Locally the second round is 304 revalidations; on a first CDN visit it can be a full ~900 kB duplicate. The control that proves it: clouds.webp, the one texture not preloaded, is requested exactly once.

Fix (recommended): fetch on the main thread, where the preload cache lives, and transfer the decoded ImageBitmaps into the worker (they are transferable â€” zero copy). This not only deletes the duplication, it starts the downloads before the worker has even booted, which is what the preloads always wanted. Moderate change: an assets message in the protocol, a "bitmaps provided" path in assets.ts. Alternative: drop the preloads and accept a later download start. Do nothing costs three revalidation round-trips per visit and the occasional real duplicate.

A2 The panel schema rides in chunks that never render it low

tune.ts exports both the values (TUNE) and the panel's SECTIONS schema. The schema's label strings ("Ladder: skirts"â€¦) are verifiably present in three chunks, including the worker's and the scene's â€” webpack does not tree-shake them apart. ~4â€“5 kB of dead strings, twice.

Fix: move SECTIONS to tune-schema.ts, imported only by the panel body. Ten minutes.

A3 The globe canvas has no accessible name low

The marker buttons are labelled; the canvas itself is anonymous to a screen reader.

A4 The gates exist but nothing chains them low Â· process

Shader lint, tsc, and the golden harness each run when remembered. Nothing runs them together, and nothing runs before a push.

05Code quality & design assessment

  • Architecture â€” the composition-root + scene-modules split is right-sized. Motion and the governor remain inline (801 lines total): still the correct call; they share the frame loop's state and neither has grown. Revisit only if one does.
  • The shared uniform table is the best structural decision in the codebase: material wiring is derived from the GLSL itself and an unknown name throws at construction. There is no silent path between the shaders, the tuning schema, and the scene.
  • Comment culture â€” the shaders and scene document decisions and rejected alternatives inline, which is why three rejected cloud approaches never came back. Worth protecting.
  • Failure design â€” every environment in the fallback matrix lands somewhere designed; the worker-crash listener that Phase 2's own verification exposed is the kind of gap only adversarial testing finds. The remaining untested path is a real CDN outage pattern (slow-then-dead), which the retry + error spine should cover but has only been tested as fast-dead.
  • The tour and loader around the earth system are properly gated (wake-ahead observer, run-only-on-screen, full dispose) and share the earth's design language. No findings.
  • Determinism discipline â€” the tune-seed freeze that makes goldens byte-stable is quietly the most valuable testing idea in the project; it turns "looks the same to me" into an exit code.
